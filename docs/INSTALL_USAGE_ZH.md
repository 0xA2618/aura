## 🌟 项目简介

Aura IDE 是一款类 VS Code 极简现代化 macOS / 跨平台桌面级编码工作区。基于 **Tauri v2 + Rust 后端 + React / Monaco Editor** 构建，拥有极致轻量、内存占用低（30MB ~ 80MB）、启动迅速与原生窗口拖拽体验。

### 模块架构布局：
```text
+---------------------+---------------------------------------------------------------+
|  1 号窗口（侧边栏） | 顶部栏：[项目名称] [🌿 分支]     [◫] [⬒] | [🤖] [🌿 Git] [⚙️]  |
|  [Dir] | [Session]  |---------------------------------------------------------------|
|  - 文件树 / 检索    |                       2 号窗口                                |
|  - Git 提交泳道图   |                 （代码编辑与差异对比）                        |
|  - SCM 文件变更列表 |            [Monaco + Vim 双态模式 + DiffEditor]               |
|  -----------------  |                                                               |
|  - AI Agent 会话    +---------------------------------------------------------------+
|  - 项目自动分组     | [Terminal 1] [OpenCode 1] [+]                                 |
|  - 绿点活跃指示     |---------------------------------------------------------------|
|  - 二次确认保护     |                       3 号窗口                                |
|                     |                （下方终端与 AI 会话抽屉）                     |
|                     |          [原生 POSIX PTY / OpenCode CLI / 进程彻底清理]       |
+---------------------+---------------------------------------------------------------+
```

## ⚡ 核心功能特性 (v1.1.0)

### 🗂️ 1 号窗口：双段可调侧边栏 (`Dir` 与 `Session`)

1 号窗口采用自顶向下贯通的左侧面板，并由可上下拖拽的分割条划分为两大核心板块：

#### 📁 `Dir` 板块（工作区文件树与 Git SCM）
- **全功能文件浏览器**：支持深层目录树展开折叠，顶部提供快捷工具栏（新建文件 `+`、新建文件夹、一键折叠全部、刷新工作区）；
- **全键盘 Vim 导航**：
  - `j` / `↓`：光标向下移动（不循环）；
  - `k` / `↑`：光标向上移动（不循环）；
  - `o` 或 `Enter`：展开/折叠目录，或在 2 号窗口打开文件；
  - `a`：行内原地新建文件（输入 `name.ts`）或新建目录（输入 `dir/`）；
  - `r`：原地重命名当前项目；
  - `d`：呼出安全删除对话框（按 `Enter` 确认，按 `Esc` 取消）；
  - `yyp`：复制当前项目的绝对路径到系统剪贴板；
- **鼠标多选操作**：支持普通单击单选、`Cmd`（或 `Ctrl`）+ 单击多选追加/反选、`Shift` + 单击区间连续多选，按 **`Esc`** 清空选择；
- **原生 VS Code Git 提交泳道图**：移植自 VS Code 官方 `scmHistory.ts` 算法，分支圆点对齐，展开详情时垂直泳道向下连贯延伸；
- **秒级 Git 状态轮询**：1.5s 后台自动检测与保存即时刷新，`Changes (N)` 严格展示未提交变更。

#### 💬 `Session` 板块（OpenCode AI 智能体多会话管理）
- **按项目智能分组**：自动按当前项目路径规范化归类 AI 会话，杜绝会话数量跳变与路径不一致；
- **活跃会话绿点指示**：当前选中的项目与正在进行的 AI 会话右侧显示清爽亮眼的翡翠绿点（`bg-emerald-500`）；
- **收藏与置顶**：支持项目与会话级黄色星星（⭐）收藏，常用项目随时置顶；
- **二次确认安全删除**：
  - 项目右侧点击删除图标或按删除键，触发二次确认弹窗（支持 `Enter` 确认，`Esc` 取消）；
  - 纯英文警告提示明确告知：**仅从当前列表隐藏，绝不删除数据库底层持久化会话**，当再次打开该项目文件夹时会自动完整重载；
- **会话右键菜单**：右键单击会话支持原地修改标题、安全删除（二次确认）及收藏；
- **上下拖拽分割条**：鼠标按住 `Session` 与 `Dir` 之间的水平细分割线可自由调整上下区域高度。

---

### 🌐 顶部栏：Git 信息、Agent 中心与窗口布局控制

- **项目名称与 Git 分支指示**：
  - 左侧居中清晰展示当前打开的工作区项目名称；
  - 绿色分支图标与当前 Git 分支徽标（如 `🌿 main`），鼠标点击直接唤出 **Git 管理模态框**；
- **右上角 `Git` 专用模态框按钮**：
  - 点击右上角 `Git` 按钮一键打开源代码管理与提交弹窗（`GitModal`）；
  - 直观浏览暂存区/未暂存区文件差异、查看分栏对比、输入约定式提交说明并查看提交图谱；
- **AI Agent Bot 快速切换器**：
  - 机器人图标下拉菜单，可一键在 3 号窗口拉起并切换 `OpenCode`、`Claude Code` 等不同 Agent；
  - 支持一键安装命令配置；
- **VS Code 风格窗口布局切换按钮**：
  - `PrimarySidebarIcon`（左侧边栏切换）：一键展开 / 收起 1 号窗口（`Dir` & `Session`）；
  - `BottomPanelIcon`（下方终端切换）：一键展开 / 收起 3 号窗口（终端 / AI 抽屉）；
  - 按钮与右侧机器人图标之间配备精致细垂直分割线；
- **偏好设置按钮 (`⚙️ Settings`)**：点击或按 `Cmd+,` 打开设置弹窗。

---

### 📝 2 号窗口：代码编辑与差异对比区

- **Monaco Editor 核心**：完整语法着色、代码高亮、多光标编辑与主题自动同步；
- **双态 Vim 编辑器模式**：
  - **Normal 模式（实心方块光标）**：`ww` 快速保存文件，`qq` 快速关闭页签，支持 `h/j/k/l`、`w/b`、`dd`、`yy`、`p` 等经典移动与操作；
  - **Insert 模式（细线垂直光标）**：提供流畅自动补全与缩进，按 `Esc` 瞬切回 Normal 模式；
- **左右分栏与行内代码对比 (Diff Comparison)**：
  - 顶部即时展示代码差异统计徽标（`+新增`、`-删除`、`~修改`）；
  - 支持左右分栏（`Split`）与单栏行内（`Unified`）无缝切换；
  - 在 `Diff Comparison` 视图选项中选择 `Text Editor (Vim)` 可直接退出对比并切换回当前文件的 Vim 常规编辑模式；
- **智能 Markdown 模式过滤**：
  - `Markdown Preview Enhanced`（增强预览）与 `Markmap Mind Map`（思维导图）仅在当前打开文件为 Markdown（`.md` / `.markdown`）时展示，普通源码文件菜单保持整洁；
  - 内置大纲目录（TOC），支持点击平滑锚点跳转与滚动同步。

---

### 💻 3 号窗口：原生终端与 AI 抽屉

- **原生 POSIX PTY 终端**：直接连接 macOS `/bin/zsh -l`，完整加载本地 `~/.zshrc` 主题、语法高亮与 Powerline 图标，杜绝乱码；
- **OpenCode CLI 原生交互**：单键点击或快捷键 `Shift+Cmd+M` 唤出真实交互式 `opencode` 编程结对助手；
- **进程树递归彻底清理**：关闭终端页签时通过 `libc::kill(-pid, SIGKILL)` 与 `pkill -9 -P` 递归彻底杀掉所有子进程，瞬间释放全部内存与 CPU；
- **路径拖拽粘贴**：从 1 号窗口直接将文件或目录拖拽到终端内，自动粘贴绝对路径。

---

### 🎨 设置与个性化定制

- **全新现代化卡片下拉选择 (`CustomSelect`)**：
  - 彻底替换原生粗糙的 HTML `<select>` 标签，采用独立圆角轻量卡片项；
  - 移除横向细分割线，主题选项去除多余颜色圆点，纯净直观；
  - 支持点击外部自动收起与 `Esc` 键退出；
- **实时主题切换**：支持 6 款精心调优的高对比度现代主题（包括 `Light 2026` 极简浅色、`VS Code Dark Modern`、`Gruvbox Dark`、`One Dark Pro`、`Nord`、`Cyberpunk Neon`）；
- **字形实时预览**：字号 10px ~ 28px 平滑缩放，字体选项（`JetBrains Mono`、`Fira Code`、`Hack Nerd Font`、`SF Mono`、`Menlo`、`Cascadia Code` 等）以对应真实字形渲染预览；
- **Open VSX 扩展市场**：在设置弹窗内直接搜索并管理 Open VSX 插件市场中的扩展。

## 🚀 下载与安装指引

### 1. macOS 平台

#### 安装步骤：
1. 从 [Releases 页面](https://github.com/0xA2618/aura/releases) 下载最新的安装包：
   - **`Aura_1.1.0_aarch64.dmg`**（适用于 Apple Silicon M1/M2/M3/M4 芯片）
   - **`Aura_1.1.0_x64.dmg`**（适用于 Intel 处理器）
2. 双击打开 `.dmg` 镜像，将 **Aura.app** 拖入 **Applications（应用程序）** 文件夹；
3. 打开 Launchpad（启动台）或 Spotlight 搜索 **Aura** 即可启动。

#### 首次启动提示“无法打开，因为无法验证开发者”解决办法：
由于开源版本暂未加入付费 Apple Developer 商业证书公证，macOS Gatekeeper 会拦截未签名应用。请通过以下两种方式之一解除：
- **方式一（图形界面）**：按住键盘 `Control` 键，鼠标右键点击 `Aura.app`，选择“打开”，在弹出的提示框中点击“打开”即可（仅需操作一次）；
- **方式二（终端命令）**：打开终端执行以下命令，清除下载隔离属性：
  ```bash
  xattr -cr /Applications/Aura.app
  ```

---

### 2. 本地源码运行与构建

如果您是开发者并希望从源代码运行或打包，请确保本地已安装：
- **Node.js** (v18+) 及 **pnpm**
- **Rust** 工具链 (`rustc` & `cargo`)

```bash
# 1. 克隆代码仓库
git clone https://github.com/0xA2618/aura.git
cd aura

# 2. 安装前端依赖
pnpm install

# 3. 启动开发模式（支持毫秒级 HMR 热更新与 Rust 原生联调）
pnpm tauri:dev

# 4. 构建生产发布包 (.app 与 .dmg)
pnpm tauri:build
```
打包输出路径位于：`src-tauri/target/release/bundle/dmg/`。

## ⌨️ 核心快捷键指南

| 快捷键 | 功能描述 |
|---|---|
| **`Ctrl+h`** | 焦点瞬间跳入 **1 号窗口**（左侧目录树与会话） |
| **`Ctrl+k`** | 焦点瞬间跳入 **2 号窗口**（代码编辑区） |
| **`Ctrl+l`** | 焦点瞬间跳入 **3 号窗口**（终端 / OpenCode） |
| **`Cmd+d`** | 在 3 号窗口新建一个原生 Terminal (zsh) 终端 |
| **`Shift+Cmd+m`** | 在 3 号窗口新建原生 OpenCode 智能对话抽屉 |
| **`Cmd+w`** | 2号窗口关闭当前文件 / 3号窗口关闭当前终端会话 |
| **`Cmd+qq`** | 1.2 秒内连续按两次小写 `q` 退出应用（防误触退出门禁） |
| **`Cmd+,`** | 打开偏好设置模态框（外观主题、全局字体、插件扩展） |
| **`Cmd+=/+` / `Cmd+-/_`** | 缩放当前活动窗口字号（1号窗口锁定 14px，2/3号窗口可动态缩放） |
| **`Esc`** | 清空 1 号窗口多选文件 / 退出各类上下文菜单与弹窗 |
| **`ww`** *(Normal 模式)* | 快速保存当前文件 |
| **`qq`** *(Normal 模式)* | 快速关闭当前文件页签 |
