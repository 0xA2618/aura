## 🌟 项目简介

Aura IDE 是一款类 VS Code 极简现代化 macOS / 跨平台桌面级编码工作区。基于 **Tauri v2 + Rust 后端 + React / Monaco Editor** 构建，拥有极致轻量、内存占用低（30MB ~ 80MB）、启动迅速与原生窗口拖拽体验。

### 三栏贯通式架构：
- **1 号窗口（左侧贯通目录树与 Git 泳道）**：全键盘 Vim 风格操作、鼠标多选、文件拖拽、官方 VS Code 原生 Git 提交泳道与秒级变更检测；
- **2 号窗口（右上方代码编辑与对比区）**：Monaco Editor 代码着色、双态 Vim 模式、Markdown 预览与 Monaco DiffEditor 差异对比器；
- **3 号窗口（右下方终端与 AI 抽屉）**：原生 POSIX PTY 交互式终端（真实加载 `~/.zshrc`）、OpenCode CLI 原生智能会话抽屉、关闭时全进程树彻底清理。

## 🚀 下载与安装指引

### 1. macOS 平台

#### 安装步骤：
1. 从 Releases 页面下载最新的安装包 `Aura_<version>_aarch64.dmg`（适用于 Apple Silicon M1/M2/M3/M4）或 `Aura_<version>_x64.dmg`（适用于 Intel 芯片）；
2. 双击打开 `.dmg` 镜像，将 **Aura.app** 拖入 **Applications（应用程序）** 文件夹；
3. 打开 Launchpad（启动台）或 Spotlight 搜索 **Aura** 即可启动。

#### 首次启动提示“无法打开，因为无法验证开发者”解决办法：
由于开源版本暂未加入付费 Apple Developer 商业证书公证，macOS Gatekeeper 会拦截未签名应用。请通过以下两种方式之一解除：
- **方式一（图形界面）**：按住键盘 `Control` 键，鼠标右键点击 `Aura.app`，选择“打开”，在弹出的提示框中点击“打开”即可（仅需操作一次）；
- **方式二（终端命令）**：打开终端执行以下命令，清除下载隔离属性：
  ```bash
  xattr -cr /Applications/Aura.app
  ```

---

### 2. 本地源码运行与构建

如果您是开发者并希望从源代码运行或打包，请确保本地已安装：
- **Node.js** (v18+) 及 **pnpm**
- **Rust** 工具链 (`rustc` & `cargo`)

```bash
# 1. 克隆代码仓库
git clone https://github.com/your-username/aura.git
cd aura

# 2. 安装前端依赖
pnpm install

# 3. 启动开发模式（支持毫秒级 HMR 热更新与 Rust 原生联调）
pnpm tauri:dev

# 4. 构建生产发布包 (.app 与 .dmg)
pnpm tauri:build
```
打包输出路径位于：`src-tauri/target/release/bundle/dmg/`。

## ⌨️ 核心快捷键指南

### 1. 窗口流转与全局控制
| 快捷键 | 功能描述 |
|---|---|
| **`Ctrl+h`** | 焦点瞬间跳入 **1 号窗口**（左侧目录树） |
| **`Ctrl+k`** | 焦点瞬间跳入 **2 号窗口**（代码编辑区） |
| **`Ctrl+l`** | 焦点瞬间跳入 **3 号窗口**（终端 / OpenCode） |
| **`Cmd+b` / `Ctrl+b`** | 显示 / 隐藏左侧 1 号窗口（支持点击图标、快捷键或向左拖动小于目录宽度自动收起） |
| **`Cmd+d`** | 在 3 号窗口新建一个原生 Terminal (zsh) 终端 |
| **`Shift+Cmd+m`** | 在 3 号窗口新建原生 OpenCode 智能对话抽屉 |
| **`Cmd+w`** | 2号窗口关闭当前文件 / 3号窗口关闭当前终端会话 |
| **`Cmd+qq`** | 1.2 秒内连续按两次小写 `q` 退出应用（防误触退出门禁） |
| **`Cmd+,`** | 打开偏好设置模态框（切换中英文、换肤主题等） |
| **`Cmd+=/+` / `Cmd+-/_`** | 缩放当前活动窗口字号（1号窗口锁定 14px，2/3号窗口可动态缩放） |

### 2. 1 号窗口：目录树操作
- **鼠标多选**：
  - 常规单击：单选该项目；
  - `Cmd`（或 `Ctrl`）+ 单击：多选追加 / 反选；
  - `Shift` + 单击：区间连续多选；
  - 按 **`Esc`**：清空所有已选中的项目。
- **键盘 Vim 导航**：
  - `j` / `↓`：光标向下移动（不循环）；
  - `k` / `↑`：光标向上移动（不循环）；
  - `o` 或 `Enter`：展开/折叠目录，或在 2 号窗口打开文件；
  - `a`：行内原地新建文件（输入 `name.ts`）或新建目录（输入 `dir/`）；
  - `r`：原地重命名当前项目；
  - `d`：呼出安全删除对话框（按 `Enter` 确认，按 `Esc` 取消）；
  - `yyp`：复制当前项目的绝对路径到系统剪贴板。

### 3. 2 号窗口：Vim 编辑器交互
- **Normal 模式（方块光标）**：
  - `h / j / k / l`：左、下、上、右移动光标；
  - `i`：在当前光标处进入 Insert 模式；
  - `o`：在当前行下方换行并直接进入 Insert 模式；
  - `ww`：快速保存当前文件（亦支持标准 `Cmd+s`）；
  - `qq`：快速关闭当前文件页签（亦支持标准 `Cmd+w`）。
- **Insert 模式（细线光标）**：
  - 正常输入任何代码与字符；
  - 按 **`Esc`** 键瞬间退出并返回 Normal 模式。

## 🧩 外部依赖与降级说明

Aura IDE 采用自包含架构设计，用户电脑上**未安装可选依赖亦可直接使用核心功能**：
- **`Git`**（推荐安装）：工作区有修改时显示 Changes 变更列表与分支泳道。若未安装 Git，Git 视图会优雅保持为空，不影响基础编辑。
- **`OpenCode CLI`**（可选）：用于启动 `Shift+Cmd+m` 的 AI 对话抽屉。未安装时仅影响 AI 会话启动，不影响常规终端与编辑器。
- **`Node.js`**：IDE 运行期完全不需要 Node.js 环境。仅当您在内置终端中调试前端工程时按需使用。
- **`Nerd Font 字体`**：已内置智能字体回退链（优先加载 Hack Nerd Font，自动回退到 macOS 自带高清等宽字体 Menlo/Monaco，保证绝不乱码）。
